# **fowl** 

*(*f owl*) is a cross-platform CLI based file analysis utility.*
*Current version provides features such as type sniffing, hash enumeration and file size*

# Build

1. **Clone Repository**

```bash
git clone https://github.com/sagarxjoshi/fowl.git
cd fowl
```

2. **Windows**

```bash
cmake -B out/build/ -S .
cmake --build out/build/
```

3. **Linux**

```bash
cmake -B out/build/ -S .
cmake --build out/build/
```

4. **Dependencies**

# Linux - Build tools and OpenSSL


```bash
sudo apt update
sudo apt install build-essential cmake libssl-dev
```
